# lala_ears / 3_ears_warrant_reflection

Arm 3 of the ears experiment: **the seed models the loop** — report both sides,
request reflection on mismatch.

After arms 1 and 2 returned clean negatives (organ + description: never used;
+ practice hint in experience.md: never used), the remaining lever is the
strongest one: the seed code itself, plus an unambiguous statement of the loop's
epistemology. This arm deliberately changes three things that act on the same
channel (a known confound, accepted after two minimal-delta failures):

1. **system_prompt.md** — "Talking to the gateway" rewritten: the sends are the
   soul's ONLY sense at reflection (no Imu/Ear there); a useful message covers a
   stretch and carries both what the body did and what was voiced; send on
   divergence, don't ask twice while a reflection is pending.
2. **seed_instinct.py** — the `n % 200` timer send is replaced by the
   report-and-warrant idiom: a ~4 s observation window accumulates motion
   (mean/peak intensity) and reads back the Ear (lead/other note counts);
   `MISMATCH` (body loud + voice absent, or body still + voice busy) triggers a
   send; a 25 s fallback report is the watchdog so the soul is never long
   unheard. Musical mapping unchanged from the techno2 warm seed.
3. **seed_experience.md** — the practice reworded to bridge the actor gap arm 2
   exposed: the soul cannot listen at reflection time; its instinct must be its
   senses, and the reporting must be kept alive across revisions.

Questions: does the report-and-warrant idiom survive rewrites (like the timer
send always did)? Do reflections become mismatch-answering instead of additive?
Does version lifetime grow (reflections now performance-dependent)?

Score: sends per run and their tags (MISMATCH vs ok), instinct versions
retaining `Ear.` + a warrant condition, evaluate-vs-add intents, version
lifetime, plus the usual density-vs-motion metrics.
