# lala_ears / 4c_inherited_experience

Arm 4c: **experience continuity** — the first probe of the triad's memory
layer across runs.

Byte-identical to `4_timed_ears` (same seed code, same organ, same prompts)
except `seed_experience.md`, which is the FINAL evolved experience
(033_195.md) of arm-4 run 20260703_134522 — the run that fixed its own report
cadence, throttled the machine-gun lead, and calibrated against measured
peaks. Generation 2 starts with generation 1's lessons but generation 0's
code.

Questions:

1. **Transfer** — does gen 2 skip the rediscoveries? Gen 1 spent reflections
   on: startup-timer init, machine-gun throttling, washout blending, chord
   refractory. All four lessons are in the inherited notes. If they're
   applied in the first reflection or two instead of re-derived mid-run,
   experience carries.
2. **Headroom** — with the basics inherited, where does gen 2 spend its
   reflections? New territory would be the payoff; re-deriving despite the
   notes would say experience is read but not trusted.
3. **Bias inheritance** — the notes also carry gen 1's enthusiasm for
   Periodicity/AlphaBeta lockstep. Does gen 2 import that bias uncritically?
   (Inherited experience transmits mistakes as faithfully as lessons.)

Score: reflections-to-first-application of each inherited lesson, plus the
usual arm-4 metrics. Compare against the two fresh arm-4 runs as the
no-inheritance baseline.
