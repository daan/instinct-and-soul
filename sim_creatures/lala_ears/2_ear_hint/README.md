# lala_ears / 2_ear_hint

Arm 2 of the ears experiment: **capture organ + seeded practice.**

Identical to `1_just_ears` (same Ear organ, same system prompt, same character,
same warm seed instinct with its periodic send) except for one delta in
`seed_experience.md`: a "practice I keep" section telling the soul, in its own
voice, to listen back via `Ear.recent` and compare what it voiced against what
the body did before revising.

Arm 1's result (20260703 run): with availability + description alone, the soul
never used, mentioned, or noted the Ear in 24 versions — deafness is a stance
problem, not an access problem. This arm asks two questions:

1. Does the seeded practice get *used* — do instinct versions read `Ear`,
   do reflections evaluate the previous change against it?
2. Does it *persist* — experience.md is under the same churn pressure as the
   code; the soul prunes what doesn't feel like producing. Watch whether the
   practice section survives successive experience rewrites.

Score: grep instinct versions for `Ear.`, grep experience versions for the
practice section, count evaluate-vs-add intents, and the usual density and
churn metrics.
