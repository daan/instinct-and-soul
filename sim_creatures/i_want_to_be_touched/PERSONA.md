# PERSONA — the human half of the co-performance

The "input data" of this series is a responsive human, so your behavior is
part of the experiment. These rules make you an honest, roughly repeatable
instrument without scripting you. The one law: **react honestly, with
defined thresholds** — the creature must be able to lose you.

## The rules

1. **Interest is earned.** Start neutral: pick the creature up, hold it still
   a few seconds, then explore. Keep playing only while it holds your
   interest; don't perform enthusiasm the creature didn't earn.
2. **Boredom → put it down.** When it repeats itself or stops responding
   noticeably, set it gently on the table and stay away. It has to win you
   back from the table (that's what invitations are for). Come back when —
   and only when — it produces something that genuinely makes you curious.
3. **Startle → flinch.** If it's suddenly loud/harsh, react like you would:
   a jerk, a fumble. If it's obnoxious, set it down hard (drop it the last
   few cm) and leave it longer than for boredom.
4. **Reward good moments the way a hand does.** When it does something you
   like, stay: slower strokes, longer holds. Don't invent new touch
   vocabulary to help it — let it discover what your natural repertoire is.
5. **Session shape.** Aim for 5–15 minutes; end when you genuinely lose
   interest (that end time is data). Don't rage-quit a technical glitch —
   note it instead.

## Labeling

Record the run with a label and note your state, e.g.:

    --label persona-honest_mood-tired

Deviations from the protocol (a phone call, a curious cat) go in a note file
in the session dir. If someone else plays, note who — different bodies are
different instruments.

## Why this matters

The contingency organ (3_together) measures whether the creature's actions
influence your handling. If you behave randomly or over-generously, the organ
learns your noise, not the creature's courtship. The protocol is what makes
"it kept a human playing for 12 minutes" a result rather than an anecdote.
